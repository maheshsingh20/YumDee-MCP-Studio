# yumdee-Mcp-studio

Open-source, all-in-one TypeScript toolkit for the MCP ecosystem. Includes a visual debugger, community server registry, orchestration layer, and compliance benchmarking.

## Packages

- **`@yumdee/mcp-studio-core`** — Session recording format + MCP client abstraction
- **`@yumdee/mcp-studio-inspector`** — Web UI debugger + replay tool
- **`@yumdee/mcp-studio-registry`** — Community server directory + CLI
- **`@yumdee/mcp-studio-agent-kit`** — Multi-server orchestration layer
- **`@yumdee/mcp-studio-bench`** — Compliance & reliability scoring

## Quick Start

```bash
pnpm install
pnpm dev          # Start all services
pnpm build        # Build all packages
pnpm test         # Run tests
pnpm lint         # Lint all packages
```
